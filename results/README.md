# Deployment evidence

`tp2/` contains functional, capacity, profile, collective and model-throughput receipts from the existing two-Spark cluster. The deployment package retains the named final matrices and cable summaries as reproducible evidence; historical measurements are described in `tp2/optimization/`.

Large or machine-specific artifacts such as full Docker inspection JSON, server logs, per-second memory streams, and profiler traces are ignored by Git but remain on the user's disk. Nothing was removed to curate the release. These receipts do not qualify a fresh cluster, establish universal quality equivalence, or prove production readiness. See [artifact provenance](../tp2/PROVENANCE.md).
